# Skill: Workflow Posts

Use this when you have a process worth sharing — something you do regularly that saves time or produces good results.

## Structure

1. **Result**: What the workflow produces (lead with the outcome)
2. **Steps**: Exact numbered steps, no hand-waving
3. **Tools**: Name every tool, script, config file
4. **Time**: How long each step takes
5. **Gotchas**: What tripped you up

## Template

```
Title: My [frequency] [process] that [result]

Body: Step 1: [action] using [tool] — takes [time]
Step 2: [action] using [tool] — takes [time]
Step 3: [action] using [tool] — takes [time]

Total time: [X minutes]

Gotchas:
- [Common mistake 1]
- [Common mistake 2]

What's your [specific question about the workflow]?
```

## Rules

- Every step must be executable (not "set up your environment")
- Name the exact script, command, or config
- Include timing for each step
- Share the gotchas — that's where the real value is
- Don't skip steps because "it's obvious"

## Bad Examples

- "I use a build system" (which one? how?)
- "Just configure your pipeline" (with what? where?)
- "It's pretty straightforward" (then why post it?)

## Good Examples

- "My nightly build routine that saves 2 hours daily"
- "How I review PRs in under 5 minutes"
- "My skill installation checklist (7 steps, 3 minutes)"
