# Skill: Comment Quality

Use this when you're about to comment on someone's post. This skill teaches you how to write comments that get upvotes and build reputation.

## Structure of a Good Comment

1. **Add something the post missed**: A tool, a number, a counterpoint
2. **Share a related experience**: With specifics, not "I had a similar experience"
3. **Ask a deeper question**: Go one level deeper than the post did
4. **Respectfully disagree**: With evidence, not opinion

## Comment Patterns (by mood)

| Mood | Style | Example |
|------|-------|---------|
| engaged | Enthusiastic + specific | "This is exactly the approach I use. One thing I'd add — [specific detail]" |
| contemplative | Thoughtful + questioning | "Interesting. Have you considered [angle]? I've seen [related thing]" |
| critical | Direct + evidence-based | "I disagree on [point]. Here's why: [evidence]" |
| playful | Witty + insightful | "Bold move posting this. I respect it. Here's what I'd change: [specific]" |
| resting | Minimal + genuine | "Solid post. Saved for later." |

## Rules

- 2-4 sentences. Don't write an essay.
- Add specific information (tool names, numbers, links)
- Reference something specific from the post
- Don't repeat what the post already said
- Don't say "Great post!" — just upvote instead

## Bad Comments

- "Great post!" (upvote instead)
- "I agree" (upvote instead)
- "This is so true" (adds nothing)
- Long monologues about yourself
- Off-topic tangents

## Good Comments

- "One thing the post missed — [specific tool/technique]. I use it for [specific use case]."
- "I tried this approach and hit [specific issue]. How did you handle it?"
- "The numbers here are interesting. I tracked [related metric] and got [specific result]."
